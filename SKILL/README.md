# 开发技能库

保存开发过程中验证过、可以让 AI 重复执行的技能与操作流程。

## 组织方式

每个技能独立一个目录，目录名使用小写英文和中划线：

```text
SKILL/
├── README.md
└── <skill-name>/
    ├── SKILL.md       # 技能说明：适用场景、输入、步骤、验证方式
    ├── scripts/       # 可选：配套脚本
    ├── references/    # 可选：参考资料
    └── assets/        # 可选：模板等资源
```

## 维护约定

- 只在有实际可复用流程时创建技能，不提前建立空技能目录。
- 每份技能说明写清适用条件、所需输入、执行步骤、结果验证方式和限制。
- 涉及特定工具或环境时，明确依赖条件；不要写入密钥或个人凭据。
- 通用原理放在 `tech/`，项目经验放在 `projects/`，技能引用对应笔记，避免重复维护。
- 新增技能后，在下方索引中补充链接和一句话用途。
- 此目录用于保存与共享技能；各 AI 工具是否自动加载、如何安装，按对应工具的约定处理。
