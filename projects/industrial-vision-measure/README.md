## 架构

```
相机 SDK 回调 ──► 采集线程 ──┬─► 帧缓冲（只留最新帧）──► 测量线程 ──► 点集 ──► 元素拟合 ──► 结果
                             └─► 深拷贝 ──► 渲染线程（生产者-消费者）──► UI
```

- 三条线程：**采集 / 测量 / UI 渲染**
- 帧交接：显示侧**拷贝**；测量侧取相机接口里的**实时帧**
- 渲染：离屏渲染 + 独立渲染线程 + 生产者消费者，取帧时判断"帧是否变化"
